## Measurement method (for reproducing numbers above)

- Whole-service CPU from the systemd cgroup (`cpu.stat` of `miniguard.service`)
  — counts every process including the QEMU judge; process names are masked by
  design (`process_mask`), so identity is by pid / exe / cgroup (§6.5).
- Per-thread CPU from `/proc/<pid>/task/*/stat` (user vs kernel).
- Hot functions: `perf record -e cpu-clock:u` on the live stripped daemon;
  addresses named by matching their code bytes against an unstripped rebuild.
- Syscalls: `perf trace -s` (tracepoints, not ptrace — `strace` would trip the
  daemon's anti-debug self-protection).

Baseline 2026-11-04 (`54df4d38`): `miniguard.service` 44.1% of one core —
QEMU judge 27.2% (software emulation, `-accel tcg`), daemon 16.5%
(5.7% user + 10.9% kernel, mostly `/proc` open/read/readlink).
